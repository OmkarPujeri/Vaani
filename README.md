# Vaani

Vaani helps families preserve an elder's voice memories as private, beautifully structured cards.

Record a memory, turn the transcript into a keepsake card, and keep it close in a family archive.

## Run

Open `Vaani.xcodeproj` in Xcode and run the `Vaani` scheme on an iPhone or iPad.

The `Package.swift` file is kept for source portability, but the Xcode project is the recommended way to run the app.
